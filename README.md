
# Deloitte Data Analytics Job Simulation (Forage)

## Overview
This repository contains analytics work completed as part of the Deloitte Data Analytics Job Simulation via Forage.

## Key Tasks
- Built a Tableau dashboard to analyze factory-wise unhealthy machine counts.
- Used calculated fields and aggregations to derive operational insights.
- Classified employee compensation equality scores into Fair, Unfair, and Highly Discriminative categories using Excel.

## Tools Used
- Tableau
- Microsoft Excel

## Disclaimer
This project is part of a virtual job simulation for educational purposes.
